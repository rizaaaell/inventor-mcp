# CLAUDE.md

Repo ini adalah fork inventor-mcp yang sedang dikembangkan untuk Autodesk Inventor 2027.

- Rencana kerja, aturan kerja, dan log progres ada di `PLAN.md`. Baca sebelum mengerjakan apa pun di repo ini.
- Kerjakan satu fase per perintah, lalu berhenti dan laporkan. Jangan lanjut tanpa persetujuan.
- Catatan perbedaan API Inventor 2027 ada di `docs/inventor-2027-notes.md`.
- Bahasa komunikasi dengan pemilik proyek: Bahasa Indonesia. Kode, komentar kode, dan pesan commit: bahasa Inggris.
